# 動画編集アプリ 🎬✨

誰でも使いやすく、高品質な動画が作れるブラウザ動画編集アプリです。CapCut風のダークテーマUIです。

## できること

- ドラッグ＆ドロップでメディアをインポート
- トリミング（スライダーで切り取り）
- ワンタップ色補正（明るさ・コントラスト・彩度）
- テキストオーバーレイ
- アスペクト比の切り替え（16:9 / 9:16 / 1:1）
- 速度・音量・回転の調整
- WebMでエクスポート（音声つき、最大1080p）
- 6秒のサンプル動画付き（ブラウザ内ですぐ試せます）

すべての処理はブラウザ内で行われます。

## 使い方

`index.html` をブラウザで開くだけで使えます。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で main ブランチを選択してください。
